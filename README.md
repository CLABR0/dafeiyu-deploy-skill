# 一键部署大肥鱼

**AI 先检查和配置；需要你扫码或确认时才开口；你操作完，它接着验收。**

`dafeiyu-deploy` 是一个 Windows Skill，用来部署或核查运行在 DSH2 上的大肥鱼（Aurabot），把 QQ、抖音、记忆和创作联动的配置、登录提示、验收串成一轮。它不会把 DSH1 当作 DSH2，也不会覆盖正在使用的安装目录。

## 开始使用

将 [`skills/dafeiyu-deploy`](skills/dafeiyu-deploy) 整个目录复制到你的 AI 助手的 Skills 目录。用 Codex 时，放到 `$CODEX_HOME/skills`；如果未设置 `CODEX_HOME`，则放到 `~/.codex/skills`。在新对话发：

> 用 $dafeiyu-deploy 一键部署大肥鱼。先检查现有环境，需要我扫码或确认身份时再提示；我操作完后继续验收。

| 你的环境 | Skill 会做什么 |
| --- | --- |
| 已装 DSH2 和相关插件 | 核对当前实例、账号和联动状态；已登录的不重复扫码。 |
| 有完整且可信的本地资产包 | 校验 `assets`，在空目录部署，启动后继续登录和验收。 |
| 全新电脑，只有这个仓库 | 先告诉你缺什么。仓库不自带 DSH2 程序、第三方插件、浏览器或模型，需另行准备。 |

## 扫码后会发生什么？

助手会说明在哪个窗口、用哪个账号、操作完回什么。QQ 需要官方客户端和可用的 QQ 网关；抖音优先展示本轮官方登录码，取不到时指引你在原登录窗口操作。模型密钥只在本机设置里填，不发到对话。最后分开汇报**已安装、已登录、已验证**，不会把打开窗口当成登录成功。

## 仓库里有什么？

- [Skill 入口](skills/dafeiyu-deploy/SKILL.md)：部署、检查和登录流程。
- [人工操作提示清单](skills/dafeiyu-deploy/references/login-and-verify.md)：什么情况下该请用户扫码、确认账号或填写设置。
- [验收口径](skills/dafeiyu-deploy/references/verification.md)：哪些状态算验证成功，哪些必须实测。

这是独立的部署辅助项目，不是 DeepSeek、腾讯或抖音的官方发行版。仓库不含登录态、私信、个人密钥或完整离线包；默认验收不发送消息、不点赞、不评论、不发布作品。
