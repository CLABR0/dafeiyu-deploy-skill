# 验证口径

- `setup.ps1 -Mode Inspect` 校验本地用户提供的资产，不会安装；`-Mode Verify` 检查指定目录内的文件，不等于插件已加载或账号已登录。
- 原有完整本地资产包曾在全新 Windows x64 隔离目录通过离线安装和启动。公开源码仓库不含该资产包；在新机器应重新核验，不套用原测试结果。
- 登录验收必须确认目标进程和数据目录一致；QQ 以网关已连接、机器人登录及身份核验为准；抖音以原插件使用的会话登录状态为准。扫码或打开窗口不等于登录成功。
- 不公开真实登录二维码、账号、聊天、令牌、设备信息或安装日志。未经真实验收，不声称能收发消息或发布作品。
