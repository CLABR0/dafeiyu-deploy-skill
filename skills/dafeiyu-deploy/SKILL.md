# 一键部署大肥鱼

这是源码版，仅包含 Skill 文档与脚本，不附带 DSH2、第三方插件、运行时或用户数据。不操作 DSH1。先区分现有安装和新部署；不要复制浏览器资料、Cookie、私信或密钥。

1. **现有安装：** 先检查 DSH2 的真实进程、数据目录和插件页面。`scripts/login.ps1 -Action Status -Root <DSH2数据根目录>` 只在实际实例路径和抖音数据目录相符时读状态。脚本无法匹配时从已确认的客户端界面核查；不要套用猜测的端口或覆盖现有目录。纯核查不触发扫码或改设置。
2. **新部署：** 只有用户已提供完整的本地资产目录（`manifest.json`、运行时、插件、模块及 wheelhouse）时才运行安装器。先执行 `scripts/setup.ps1 -Mode Inspect -AssetRoot <本地资产目录> -Root <空目录>` 校验，再以同参数切换到 `-Mode Install`。用生成的 `Start-DSH2.cmd` 启动。没有兼容资产包时直接说明缺项，不下载来源不明的整合包，也不声称本仓库可独立离线安装。
3. **部署或恢复登录前，必须读取** [人工提示与登录验收](references/login-and-verify.md)。助手先自己做能完成的检查，再在对话里提示当前真正需要用户操作的项目，写清窗口、平台、动作、做完回什么。可并行的合并，已经登录的不重扫。用户完成后从原步骤继续验证，不要求重发部署命令。
4. 区分「程序已安装」「账号已登录」「联动已验证」。没实测的真实收发、作品发布和身份绑定不要写成功。按 [验证口径](references/verification.md) 报告。测试默认不发消息、不点赞、不评论、不发布。
